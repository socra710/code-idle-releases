개인정보처리방침

시행일 · 최종 수정일: 2026년 11월 5일

CODE IDLE 운영자(이하 “운영자”)는 웹 게임과 Windows 앱을 제공하며, 개인정보를 다음과 같이 처리합니다. 이 방침은 CODE IDLE의 공식 사이트, 게임, Google 로그인 및 계정 기능에 적용됩니다.

로그인 없이 로컬로 플레이할 수 있습니다. Google 로그인은 계정 식별에 사용하며, 계정 게임 연결 시 게임 진행이 서버에 저장됩니다. 랭킹에는 닉네임과 게임 기록이 표시됩니다. Google 비밀번호는 받지 않습니다.

1. 처리하는 정보와 이용 목적

  • Google 로그인 정보: Google 계정 식별자, Firebase 사용자 식별자(UID), 이메일 주소, 기본 프로필(이름·프로필 사진 등 Google이 제공하는 범위), 인증 토큰 및 로그인 상태를 계정 인증과 세션 유지에 사용합니다. 기본 프로필은 Firebase Authentication에서 처리될 수 있으며 게임의 공개 닉네임과는 별개입니다.
  • 게임 프로필: 직접 입력한 닉네임, 중복 방지용 닉네임 식별값, 등록·갱신 시각을 프로필 관리와 랭킹 식별에 사용합니다.
  • 게임 저장 정보: 캐릭터, 레벨, 자원, 스킬, 장비·의상·장식, 활동, 목표, 의뢰, 설정 및 저장 시각을 진행 상황 저장·복원에 사용합니다. 계정 연결을 선택하면 진행 정보가 클라우드에 전송·저장됩니다.
  • 랭킹 및 동기화 정보: 시즌별 생산량·참여 시간, 닉네임, 세션·요청 식별자, 저장 버전과 접속·처리 시각을 순위 산정, 중복 보상 방지 및 안전한 동기화에 사용합니다.
  • 접속·운영 정보: GitHub Pages와 Google/Firebase 등의 인프라에서 IP 주소, 요청 시각, 기기·브라우저 정보 및 오류·보안 로그를 서비스 제공, 장애 대응 및 보안 목적으로 처리할 수 있습니다.

Google 로그인은 기본 계정 인증 범위(openid, email, profile)를 사용합니다. Gmail 메일, Google Drive 파일, 연락처, 캘린더에 대한 접근 권한은 요청하지 않습니다. 광고 타기팅을 위해 Google 로그인 정보를 이용하거나 판매하지 않으며, 현재 게임에 별도 광고·분석 SDK를 도입하지 않았습니다.

2. 로컬 저장소와 로그인 유지

웹 버전은 브라우저의 로컬 저장소에 게임 세이브·백업·설정을 저장합니다. Windows 앱은 기기 내 앱 저장 영역에 파일을 보관합니다. Firebase 인증 기능은 로그인 유지를 위해 브라우저 저장소 등을 사용할 수 있습니다.

브라우저의 사이트 데이터 삭제 또는 기기의 저장 파일 삭제로 로컬 정보를 지울 수 있습니다. 이 경우 복구하지 못한 로컬 진행이 사라질 수 있습니다. 로컬 데이터 삭제·앱 제거·로그아웃은 서버에 저장된 계정 정보의 삭제를 의미하지 않습니다.

3. 외부 서비스와 정보 공개

운영자는 서비스 제공을 위해 Google/Firebase(인증, Firestore 데이터 저장, Cloud Functions 서버 처리)와 GitHub Pages(웹사이트 제공)를 사용합니다. 이들 사업자는 각 서비스의 약관과 개인정보처리방침에 따라 관련 정보를 처리합니다. 이용자의 닉네임·순위·생산량·참여 시간 등 랭킹 기록은 게임 내 다른 이용자에게 표시될 수 있습니다. 이메일·Google 프로필 사진·인증 토큰을 게임 랭킹에 공개하지 않습니다.

서비스별 인프라 위치에 따라 정보가 대한민국 외 국가에서 처리될 수 있습니다. Google 인증 및 글로벌 인프라의 처리 위치는 Firestore나 게임 서버의 배포 지역과 다를 수 있습니다. 외부 서비스의 처리·보관에 관한 상세 내용은 아래에서 확인할 수 있습니다.

  • Google 개인정보처리방침
  • Firebase 개인정보 보호 및 보안 안내
  • GitHub 개인정보처리방침

운영자는 개인정보를 판매하지 않으며 위의 서비스 제공, 이용자가 선택한 공개 기능 또는 법령에 따른 경우 외의 목적으로 제3자에게 제공하지 않습니다.

4. 보관과 삭제

로컬 저장 정보는 이용자가 삭제하기 전까지 기기에 남습니다. 계정 프로필·클라우드 세이브·시즌별 랭킹 기록은 계정 기능과 기록 제공을 위해 보관하며, 현재 미접속만으로 자동 삭제하지 않습니다. 삭제 요청 시 본인 확인 후 관련 계정·닉네임 등록·게임 저장·랭킹 정보의 삭제를 처리합니다. 법령상 보존 의무가 있는 경우에는 해당 범위와 기간을 안내합니다.

운영 로그와 외부 사업자의 백업은 해당 서비스의 설정·보관 정책에 따라 처리되며, 삭제가 즉시 모든 백업에 반영되지는 않을 수 있습니다. 개별 보관·삭제 상태는 아래 문의 창구를 통해 확인할 수 있습니다.

5. 이용자의 선택과 권리

이용자는 로그인하지 않고 로컬 게임을 이용하거나 로그아웃할 수 있으며, Google 계정의 연결된 앱 관리에서 CODE IDLE의 접근 권한을 철회할 수 있습니다. 권한 철회만으로 이미 저장된 게임 데이터가 자동 삭제되지는 않습니다.

개인정보의 열람·정정·삭제·처리정지 및 계정 삭제를 문의할 수 있습니다. 현재 게임 내 자동 계정 삭제 기능은 없으며 요청을 통해 처리합니다. 요청에 필요한 최소한의 본인 확인을 진행할 수 있습니다. 닉네임에는 실명·이메일 등 공개를 원하지 않는 정보를 입력하지 마세요.

6. 보호 조치

HTTPS 통신, Firebase 인증, 데이터 접근 규칙 및 서버 측 검증을 통해 무단 접근과 저장 충돌을 줄입니다. 다만 모든 장애나 보안 사고가 발생하지 않는다고 보장할 수는 없습니다. Google 비밀번호, 로그인 인증 코드 또는 인증 토큰을 운영자에게 보내지 마세요.

7. 운영자 및 개인정보 문의

서비스 운영·개인정보 문의 담당: CODE IDLE 운영자
문의 창구: CODE IDLE 공식 지원 게시판

공개 게시판에는 “개인정보 문의” 또는 “계정 삭제 요청”과 같이 요청 종류만 남겨 주세요. 이메일 주소·UID·세이브 파일·토큰 등 개인정보는 게시하지 마세요. 비공개로 확인할 내용이 있으면 공개 게시판에 적지 말고 운영자에게 비공개 접수 방법을 먼저 요청해 주세요.

8. 방침 변경

기능 또는 정보 처리 방식이 바뀌면 이 페이지의 내용과 최종 수정일을 갱신합니다. 이용자 권리에 중요한 변경은 공식 사이트나 릴리스 안내 등을 통해 알립니다.
